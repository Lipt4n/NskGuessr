# НСК Гессер

Аналог GeoGuessr, только по Новосибирску и на панорамах Яндекс.Карт. Тебе показывают случайную улицу — ставишь точку на карте, где, по-твоему, это снято. Чем ближе, тем больше очков. Один игрок, без регистрации, мультиплеера и прочего.

> ⚠️ **Это полный вайбкод.** Весь код написан Claude. Я его не писал построчно, не ревьюил и не гарантирую, что внутри всё красиво и правильно. Там, например, есть манкипатчинг внутренностей API Яндекса, чтобы спрятать номера домов. Работает у меня — и ладно. Если что-то сломалось, issues и PR приветствуются, но ожидания держите разумными.

## Что умеет

- 5 раундов, до 5000 очков за раунд (25 000 за игру)
- Случайная панорама Яндекса в пределах города: только автомобильные (не только), без снимков с телефонов (иногда бывают) и панорам внутри зданий (тоже встречаются)
- Номера домов, название улицы и ссылка «Открыть в Яндекс.Картах» скрыты
- Карта для угадывания в углу, при наведении увеличивается, её можно закрепить большой
- После раунда — твоя точка, загаданная точка, расстояние по прямой между ними и очки
- Области игры: весь город, центр или своя — рисуется на карте прямоугольником (не работает) или произвольной фигурой (а это работает)
- Режимы: без перемещения, без поворота и зума камеры 
- Таймер на раунд: выключен, 30 с, 1, 2 или 3 минуты
- Рейтинг в духе Эло с дивизионами (Бронза → Серебро → Золото → Мастер → Чемпион): за жёсткие режимы тот же счёт приносит больше рейтинга, за маленькую область — меньше
- История игр, лучший и средний счёт
- Горячая клавиша: `Пробел` — угадать / следующий раунд
- Всё хранится в браузере (`localStorage`, ключи `nskguessr.v1` и `nskguessr.apikey`) — никаких серверов и аккаунтов

## Что нужно: ключ API Яндекса

Без ключа панорамы не загрузятся. Ключ бесплатный.

1. Зайди в [кабинет разработчика Яндекса](https://developer.tech.yandex.ru/services) и подключи **JavaScript API**.
2. Открой настройки ключа и в **«Ограничение по HTTP Referer»** впиши `localhost` (и домен, если выкладываешь игру в интернет, например `something.netlify.app`). Без `http://`, порта и слеша в конце.
3. Дождись, пока статус JavaScript API станет **«Активен»**. Пока там «Не настроен», будет ошибка `Invalid api key`. После создания или правки ключа иногда приходится ждать до часа.
4. Вставь ключ в игре при первом запуске. Нужен ключ именно **JavaScript API**, а не геокодера.

## Как запустить

Двойной клик по `index.html` **не сработает**: страница откроется как `file://`, браузер не отправит Referer, и Яндекс отклонит ключ. Нужен локальный сервер или хостинг.

**macOS / Linux** (если есть Python):

```bash
python3 -m http.server 8765
```

Потом открой `http://localhost:8765`.

**Windows без Python:** положи `start.bat` рядом с `index.html` и запусти двойным кликом. Это маленький веб-сервер на встроенном PowerShell: сам найдёт свободный порт (8765–8785) и откроет браузер. Окно не закрывать, пока играешь.

**В интернете:** закинь папку на [Netlify Drop](https://app.netlify.com/drop) или GitHub Pages и добавь полученный домен в Referer ключа.

**С другого компа в локалке:** открывай по имени ноута, например `http://MacBook.local:8765`, и добавь это имя в Referer (цифровые IP Яндекс не принимает).

## Ограничения

- **Лимиты Яндекса.** Если играть много, бесплатный суточный лимит ключа может закончиться, и до следующего дня будет `Invalid api key`.
- Отличать автомобильные панорамы приходится эвристикой (у них есть стрелки движения вдоль дороги), так что иногда может проскочить что-то странное.
- Контур города нарисован примерно, на глаз. (Цифровой глаз клода)
- Рейтинг, история и ключ живут в `localStorage` конкретного браузера и конкретного адреса: у `localhost` и у `.local` они разные. Очистил данные сайта — всё пропало.
- Ключ API надо вводить отдельно на каждом устройстве и адресе.
- Только панорамы Яндекса, только Новосибирск (хотя свою область можно нарисовать где угодно в пределах карты).

## Как это устроено

- **Поиск места:** случайная точка внутри области (проверка «точка в многоугольнике» лучом) → `ymaps.panorama.locate` → фильтр автомобильных → проверка, что панорама в области и не слишком близко к другим раундам.
- **Очки:** расстояние по формуле гаверсинусов, `5000 · e^(−(d − 25) / 3000)`, ближе 25 м — полные 5000.
- **Рейтинг:** Эло против «сложности режима» D. Ожидаемый результат `1 / (1 + 10^((D − R) / 600))`, изменение `K · (счёт/25000 − ожидаемый)`, K = 80 в первые 10 игр, дальше 40.
- **Хаки:** API Яндекса 2.1 не передаёт `apikey` в запросы панорам — игра дописывает его сама. Номера домов и входы в здания отключены подменой методов в классе панорам.
